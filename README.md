# Course Registration System

A full-stack Course Registration web application built with Spring Boot and a JavaScript/HTML/CSS frontend.

## Project Structure

- `backend/` - Spring Boot REST API application (Spring Data JPA, MySQL)
- `Frontend/` - Web client interface (Course list, registration, enrolled courses)

## Tech Stack

- **Backend**: Java 21, Spring Boot, Spring Data JPA, MySQL
- **Frontend**: HTML5, CSS3, JavaScript (Fetch API)
- **Build Tool**: Maven

## Getting Started

### Prerequisites
- JDK 21+
- MySQL Server
- Maven (or use bundled `./mvnw`)

### Running Backend
```bash
cd backend
./mvnw spring-boot:run
```

### Running Frontend
Open `Frontend/index.html` in any web browser.
